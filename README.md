# Āēr Weather

A minimalistic WinUI 3 weather app I built for myself — designed for quick glances, not data overload. Other apps are ready for that.

It intentionally keeps things simple: just the essentials, no clutter.
Āēr aims to feel like a natural part of Windows, blending seamlessly with the system’s design language. It does so within a minimal scope, with the maximum amount of polish possible.

### Tech Stack

- Framework: WinUI 3
- Language: C#
- Platform: Windows App SDK
